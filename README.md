A simple Pokemon battle game in Python.
What You Need

Python
NumPy: pip install numpy

How to Play

Run the file
Pick moves by typing 1, 2, 3, or 4
Battle until one Pokemon faints
Winner gets money!

Pokemon Types

Fire beats Grass
Water beats Fire
Grass beats Water

Pokemon List 
Starters: Charmander, Squirtle, Bulbasaur 
Evolved: Charmeleon, Wartortle, Ivysaur
Final: Charizard, Blastoise, Venusaur


To start a battle, modify the last line in the code:
Example: Charmeleon vs Charmander
Charmeleon.fight(Charmander)

That's it! Have fun!
